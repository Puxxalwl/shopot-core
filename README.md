# shopot

Серверлесс P2P-мессенджер: **ноль своих серверов**, история только на устройстве.
Реализация — чистый Zig (std-only, без пакетов и OS-зависимостей): [`zig/`](zig/).

C++-версия (v0.2.4, FTXUI/MQTT/WebRTC) удалена из master; архив — тег `cpp-archive`.

## Сборка

Нужен только [Zig 0.17.0](https://ziglang.org/download/). Затем:

    make            # = cd zig && zig build -Doptimize=ReleaseFast
    make test

Бинарник: `zig/zig-out/bin/shopot-zig`.

## Релей (скрытие IP)

```bash
# на любом сервере (VPS):
./shopot relay 0.0.0.0:9000

# у себя:
> invite bob relay vps.example.com:9000
# → код уходит bob-у; bob делает add — и видит только адрес релея
```

## Использование

    shopot-zig init          # личность: ~/.shopot/zig-seed (0600)
    shopot-zig serve         # демон: ядро + UDS-апи (~/.shopot/api.sock)

Интерфейса командной строки нет: единственный клиент — GUI, подключается
к ядру по UDS бинарным кадровым протоколом (типизированные ответы,
машинные коды ошибок, события) — спецификация для авторов клиента:
`zig/docs/CORE-API.md` (API 1.0.0).

Добавление друга — одно действие: `CREATE_INVITE` выдаёт односторонний код
(`shopot://i/...`), держатель делает единственный `ACCEPT_INVITE`; контакт,
сессия и доставка поднимаются ядром сами (LAN-поиск, автодозвон,
офлайн-outbox, подтверждения доставки ACK).

## Криптография

- XX-подобное рукопожатие (X25519 + Ed25519, подписи транскрипта)
- Двойное шифрование сообщений: рэтчет-цепочки поверх AEAD-потока
- Звонки: кадры 20 мс, ключ кадра = HKDF(секрет звонка, seq), транспорт — свой AEAD
- Хранилище: append-only AEAD-лог, ни одного байта открытого текста

См. `zig/docs/PROTOCOL.md`, SECURITY.md.
